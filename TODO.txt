python sudoku solver program
1) use pygame-ce
2) make setup.sh, play.sh
3) edit problem: 문제를 입력하는 방식
  - <edit> 버튼이 <done> 버튼으로 바뀜
  - 왼쪽 마우스 버튼을 누르면, 1~9, clear 패드 출력.
  - 1~9 버튼을 누르면 해당 칸에 해당 숫자가 기록
  - clear 버튼을 누르면 해당 칸의 숫자를 지움
  - <done> 버튼 누르면 빠져나감
4) solve: 문제를 푸는 방식
  - 빈 칸들을 랜덤하게 검색후, 이 칸에 대해서 숫자가 확정될 수 있는지 검사.
  - 확정한 이유에 대한 기존 숫자칸들을 highlight
  - 확정된 숫자 표시, <next search> 버튼 표시
  - 숫자가 확정되지 않으면 다른칸 검사 (현재 칸은 검색에서 제외)
  - 검사할 수 있는 모든칸이 확정되지 않으면 <Cannot solved 표시, <user solve> 모드와 <abort> 모드 선택 가능>
  - 모두 풀면 <finish> 표시
5) generate random problem: 무작위 문제 생성
  - 적절하게 무작위 문제를 생성 (edit problem 대치)
6) quit: 프로그램 종료
